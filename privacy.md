# Privacy Policy – Hermes Agent App

Last updated: 15 October 2026

Hermes Agent App is a private tool used only by its owner, Dzmitry Sviatokha, to access the owner's own Google account through Google APIs. It is not offered to the public.

**Data accessed.** With the owner's consent, the app accesses Gmail, Google Calendar, Google Drive, Contacts, Sheets and Docs data of the owner's own Google account, only to carry out tasks the owner requests.

**Processing and storage.** OAuth tokens are stored locally on the owner's machine or server. Content may be sent to the AI model provider configured in the agent solely to process the owner's requests. Google user data is not sold, not used for advertising, and not transferred to anyone else.

**Limited Use.** The app's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

**Revoking access.** Access can be revoked at any time at [https://myaccount.google.com/permissions](https://myaccount.google.com/permissions).
