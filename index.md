# Hermes Agent App

Hermes Agent App is a private personal assistant built on Hermes Agent. It is used only by its owner, Dzmitry Sviatokha, to read and manage the owner's own Gmail, Google Calendar, Google Drive, Contacts, Sheets and Docs through Google APIs. It is not offered to the public.
